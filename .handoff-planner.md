### Hard Engineering & Evidence Guardrails
1. **Zero Hallucination**: No truth scores, no invented quotes/authors/dates, unresolved findings stay `unresolved`.
2. **Retrieval Bounds**: Exactly 1 claim investigated per action, max 2 Serper queries (5 hits each, `-filetype:pdf`), max 3 candidate pages fetched, 90s monotonic deadline.
3. **SSRF IP-Pinning**: Socket-level destination IP verification against loopback/RFC 1918/CGNAT; max 3 redirects with re-resolution; 1 MB limit; 10s connect / 30s read timeouts.
4. **Defensible Dates**: Extracted strictly from JSON-LD, `<meta>`, `<time>`, or explicit bylines (never HTTP headers or URL digits).
5. **Inert DOM**: All dynamic text rendered strictly via `textContent` or `document.createTextNode()`. Zero raw `innerHTML` injection.
6. **Git Hygiene**: Stage by exact path only (`git add <path>`); stop at Push Gate for Owner approval.

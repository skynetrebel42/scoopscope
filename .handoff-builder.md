  - Do NOT modify `backend/app/safe_fetcher.py` (SSRF IP-pinning, 1 MB ceiling, redirect gates).
  - Do NOT modify `backend/app/serper_provider.py` (search query capping, API format).
  - Do NOT modify verbatim character-offset slice verification in `backend/app/passage_extractor.py` (`extracted_text[start:end] == exact_passage`).
- **DOM Rendering Security**:
  - Render all dynamic DOM text, titles, snippets, URLs, passages, citations, and export views strictly via `textContent` or `document.createTextNode()`. Zero raw `innerHTML` injection of untrusted strings.
- **Test-Driven Discipline**:
  - Always write failing tests first (`backend/tests/test_report_and_extraction.py`, `backend/tests/test_la_jurisdiction.py`, and `frontend/test_runner.html`).

- **Reporting Convention**:
